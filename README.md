# ChemVLE-LLM
ChemVLE-LLM: AI-Driven Vapor-Liquid Equilibrium Prediction System/n
Developed an interactive web-based AI tool to predict the Vapor-Liquid Equilibrium (VLE) behavior of binary mixtures using SMILES strings and operating conditions./n
Implemented an AI/LLM-enhanced model to accurately predict equilibrium temperature and vapor-phase mole fractions based on liquid-phase compositions./n
Integrated automated data visualization to generate real-time T-x-y (Temperature-Composition) phase diagrams, clearly mapping bubble and dew points at standard pressure (101.325 kPa)./n
Tech Stack: Python, Mistral-7B, Hugging Face Transformers, LoRA (PEFT), RDKit, Gradio./n
web:https://molpredai.top/
